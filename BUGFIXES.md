# 🐛 Исправления багов v2.1

## ✅ Исправлено в этой версии

### 1. Парсинг команд бота
**Проблема**: Бот не распознавал команды с символами маркеров (•, -, *)  
**Решение**: Добавлена очистка текста от маркеров перед парсингом

**Теперь работают команды:**
- `• проверить камеры` ✅
- `• проверить неделю` ✅
- `• анализ выработки` ✅
- И все остальные с маркерами

### 2. Новые команды бота
**Добавлены команды:**
- `проверить камеры` - показывает статистику снимков
- `проверить неделю` - проверяет покрытие сменами на неделю
- `проверить месяц` - проверяет покрытие сменами на месяц
- `анализ выработки` - показывает выработку за день и месяц
- `анализ часов` - показывает отработанные часы
- `статус бота` - показывает статус ИИ-бота
- `обучить бота` - запускает обучение
- `отчёт бота` - показывает отчёт
- `анализ стены` - анализирует активность на стене

### 3. Версия БД сервера
**Проблема**: Ошибка 400 Bad Request при синхронизации  
**Причина**: Сервер ожидал v7, клиент отправлял v8  
**Решение**: Обновлена версия в `server/launcher.py` с 7 на 8

## 🔧 Что ещё нужно исправить

### Критичные проблемы:

#### 1. Игры с ИИ перезагружают страницу
**Симптом**: При нажатии "Играть с ИИ" сервер обновляется и страница перезагружается  
**Причина**: `createAIGame()` использует `up()` который синхронизирует с сервером  
**Решение**: Сделать игры с ИИ локальными без синхронизации

#### 2. Автозапуск не работает
**Симптом**: Тумблер "Автозапуск с Windows" не меняется  
**Причина**: Функция `serverAutostart()` не реализована в store  
**Решение**: Реализовать функцию

#### 3. Загрузка файлов (не по 10 штук)
**Симптом**: Можно загрузить только по одному файлу  
**Причина**: Ограничение в UI компоненте  
**Решение**: Исправить компонент загрузки

#### 4. Рисунки не отображаются на стене
**Симптом**: Нарисованные рисунки не сохраняются  
**Причина**: Проблема в сохранении dataURL  
**Решение**: Исправить сохранение

#### 5. Стена постоянно обновляется
**Симптом**: Стена перезагружается каждые несколько секунд  
**Причина**: Агрессивная синхронизация  
**Решение**: Увеличить интервал синхронизации для стены

#### 6. Онлайн игры не работают
**Симптом**: Баги в крестиках-ноликах  
**Причина**: Проблемы с синхронизацией ходов  
**Решение**: Исправить логику игры

## 🚀 Инструкция по обновлению

### 1. Пересоберите проект:
```bash
npm run build
```

### 2. Перезапустите сервер:
```bash
cd server
python launcher.py
```

### 3. Обновите страницу в браузере:
- Нажмите `Ctrl+F5` для полной перезагрузки
- Или очистите кэш браузера
