# СменаЛАН — локальный сервер (Python)

Сервер раздаёт веб-приложение всем устройствам одной Wi-Fi сети и хранит **общую базу**:
отметки, графики, заявки и лента, созданные на любом телефоне/планшете/ПК, сразу видны всем.

## Установка (один раз)

| ОС | Команда |
|---|---|
| Windows | двойной клик по `install.bat` |
| Linux / macOS | `sh install.sh` |
| вручную | `python install.py` |

Установщик сам:
1. проверит Python (нужен 3.8+) и pip;
2. докачает зависимости: `pystray` (жизнь в трее), `Pillow`, `qrcode`;
3. проверит собранное приложение (папка `dist` — сборка: `npm run build`);
4. нарисует иконки и создаст ярлык **«СменаЛАН — сервер»** на рабочем столе.

## Запуск

Двойной клик по ярлыку на рабочем столе **или** в этой папке:

```
python launcher.py
```

Сервер запускается и **живёт в системном трее** (иконка возле часов).

### Меню трея (правый клик)
- **http://192.168.x.x:8080** — адрес сервера; клик — скопировать;
- **Скопировать ссылку для сотрудников** — готовая ссылка в буфере, можно отправлять в чат;
- **Показать QR-код** — сотрудник наводит камеру телефона и сразу попадает в систему;
- **Открыть админку в браузере**;
- **Настройки сервера** — порт, список IP-адресов, автозапуск вместе с Windows/Linux;
- **Перезапустить сервер**;
- **Остановить и выйти**.

## Важные файлы

| Файл | Назначение |
|---|---|
| `launcher.py` | сам сервер + трей |
| `install.py` | автоустановка и ярлык |
| `config.json` | порт и настройки (создаётся автоматически) |
| `data/db.json` | **общая база данных** всех устройств |
| `data/db.backup.json` | резервная копия базы (предыдущая версия) |
| `server.log` | журнал сервера — смотреть при проблемах |
| `tray_icon.ico / .png` | иконки (рисует установщик) |

## Если что-то не так

- **Телефоны не видят сервер.** При первом запуске Windows показывает окно брандмауэра —
  разрешите доступ для *частных сетей*. Если окно закрыли: Панель управления → Брандмауэр →
  «Разрешить взаимодействие с приложением» → добавьте `python`/`pythonw`.
- **Порт занят.** Сервер сам подберёт свободный (8080 → 8081 → …) и покажет реальный адрес в трее.
- **В трее пусто.** Запустите `python launcher.py` из консоли и читайте `server.log`.
- На Linux для трея могут понадобиться `libappindicator`/`xclip` (для буфера обмена).
