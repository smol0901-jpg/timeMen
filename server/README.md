# СменаЛАН — локальный сервер (Wi-Fi сеть)

Сервер учёта рабочих смен для работы внутри одной Wi-Fi сети: 2–9 ПК, айко-блоки (экраны) и планшеты
видят **одну базу в реальном времени** (синхронизация каждую секунду).

## Установка (один раз)

**Windows:** двойной клик по `install.bat`
**Linux/macOS:** `./install.sh`

Установщик сам:
1. проверяет Python 3.8+ и pip;
2. ставит зависимости (`pystray`, `Pillow`, `qrcode`);
3. проверяет сборку `dist/` (если нет — выполните `npm run build` в корне проекта);
4. создаёт папки `server/data` (база, файлы, резервные копии);
5. кладёт ярлык **«СменаЛАН — сервер»** на рабочий стол и печатает ссылку для сотрудников.

## Запуск

Двойной клик по ярлыку (или `python launcher.py`). Сервер:

- живёт **в трее круглосуточно**; правый клик по иконке:
  - ссылка `http://IP:8080` (клик — открыть),
  - **«Скопировать ссылку для сотрудников»** — готовая ссылка в буфере,
  - **QR-код** — сотрудник наводит камеру телефона,
  - **Настройки сервера** — порт, API-токен, автозапуск вместе с Windows,
  - резервная копия «сейчас», журнал, выход;
- хранит базу в **SQLite** (`server/data/smenalan.sqlite`) — без ограничения места;
- фото и вложения со стены/чатов — в `server/data/files`;
- **еженедельно автоматически** делает резервные копии в `server/data/backups` + зеркало `db.json`;
- пишет все запросы и события в `server.log`;
- защищён от двойного запуска; если порт занят — берёт следующий свободный.

> При первом запуске Windows спросит разрешение брандмауэра — разрешите для **частных сетей**,
> иначе телефоны не увидят сервер.

**Без трея** (серверная машина, консоль): `python launcher.py --console`

## Доступы по умолчанию

| Кто | Логин | Пароль |
|---|---|---|
| Суперадмин (неудаляемый) | `root` | `root` (пока не сменят; есть зашифрованный резервный код восстановления) |
| Песочница | `demo` | без пароля |

Сотрудников создаёт админ в разделе «Сотрудники» — пароль не обязателен, сотрудник ставит его сам.
Демо-режим отключён: база стартует чистой.

## API для датчиков и интеграций (19 эндпоинтов)

Токен задаётся в «Настройках сервера» (трей) или в Настройках админки; передаётся заголовком
`X-API-Token` или `?token=…`. Без токена запись открыта в LAN.

```
GET  /api/ping                     проверка доступности
GET  /api/health                   версия БД, аптайм, бэкапы, размер SQLite
GET  /api/state                    версия базы (для real-time)
GET  /api/db                       {version, data}
POST /api/db                       {data} — синхронизация клиентов
GET  /api/today                    кто сейчас на смене
GET  /api/employees                сотрудники (без паролей)
GET  /api/punches?date=YYYY-MM-DD  отметки за дату
GET  /api/stats?from&to            план/факт часы по сотрудникам
GET  /api/production?from&to       выработка (обвалка и т.п.)
GET  /api/logs?limit=N             журнал действий
GET  /api/sensors?limit=N          лента показаний
GET  /api/sensors/latest?name=X    последнее значение
POST /api/sensors                  {name, value, unit} — запись показания  [токен]
POST /api/backup                   резервная копия сейчас                  [токен]
GET  /api/backups                  список копий
POST /api/files                    {name, dataBase64} → {url}              [токен]
GET  /files/<имя>                  скачивание файла
GET  /api/endpoints                этот список (JSON)
```

Пример датчика температуры:

```bash
curl -X POST http://192.168.1.10:8080/api/sensors \
  -H "Content-Type: application/json" \
  -d '{"name":"temp_myasnoy","value":4.2,"unit":"°C"}'
```

## Локальный режим (без сервера)

Если сервер не запущен, приложение показывает «Локальный режим» (жёлтый индикатор) и продолжает
работать: данные хранятся в браузере устройства. Как только сервер поднимется — база
синхронизируется автоматически. Полная инструкция — в приложении: «Инструкции и API» → «Локальный режим».

## Структура файлов

```
server/
  launcher.py        сервер + трей + API + резервные копии
  install.py         автоустановка и ярлык
  requirements.txt   зависимости Python
  data/
    smenalan.sqlite  база (SQLite, бессрочно)
    db.json          зеркало базы
    files/           фото и вложения
    backups/         еженедельные копии
  server.log         журнал сервера
```
