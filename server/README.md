# СменаЛАН — локальный сервер (Wi-Fi сеть)

Сервер учёта рабочих смен: админка для ПК, PWA для телефонов/планшетов, киоск-терминал с веб-камерой.
Все устройства (2–9 ПК, айко-блоки, планшеты) видят **одну базу в реальном времени** — синхронизация каждую секунду.

## Установка (один раз)

**Windows:** двойной клик по `install.bat` · **Linux/macOS:** `./install.sh` или `python3 install.py`

Установщик сам:
1. проверяет Python 3.8+ и pip;
2. ставит зависимости (`pystray`, `Pillow`, `qrcode`);
3. проверяет сборку `dist/` (если нет — пытается `npm run build`);
4. создаёт `server/data` (база SQLite, файлы, резервные копии);
5. кладёт ярлык **«СменаЛАН — сервер»** на рабочий стол.

## Запуск

Двойной клик по ярлыку (или `python launcher.py`). Сервер:

- живёт **в трее круглосуточно**; правый клик по иконке:
  - ссылка `http://IP:8080` (клик — открыть),
  - **«Скопировать ссылку для сотрудников»**,
  - **QR-код** — сотрудник наводит камеру телефона,
  - **Настройки сервера** — порт, API-токен, автозапуск с Windows,
  - резервная копия «сейчас», журнал, выход;
- база — **SQLite** (`server/data/smenalan.sqlite`), без ограничения места;
- фото/вложения — `server/data/files`; снимки веб-камер хранятся **120 дней** и сжимаются;
- **еженедельные автокопии** в `server/data/backups` + зеркало `db.json`;
- журнал всех запросов — `server.log`;
- защита от двойного запуска; если порт занят — берётся следующий свободный.

> Первый запуск: разрешите доступ в окне брандмауэра Windows (частные сети).

**Без трея (консоль):** `python launcher.py --console`

## Доступы по умолчанию

| Кто | Логин | Пароль |
|---|---|---|
| Суперадмин (неудаляемый) | `root` | стандартный (зашифрованный резервный код восстановления — на экране входа) |
| Бухгалтерия | `buh` | `1234` |
| Песочница | `demo` | без пароля |

Сотрудников создаёт админ; изначально все без пароля — ставят сами. PIN терминала: `1234` (меняется в Настройках).

## API (21 эндпоинт, для датчиков и интеграций)

Токен — в «Настройках сервера» (трей) или в Настройках админки; передаётся `X-API-Token` или `?token=`.

```
GET  /api/ping · /api/health · /api/state · /api/db · /api/today
GET  /api/employees · /api/punches?date= · /api/stats · /api/production
GET  /api/camshots · /api/logs · /api/sensors/latest?name= · /api/backups · /api/endpoints
POST /api/db                      синхронизация клиентов (реальное время)
POST /api/sensors  {name,value,unit}        [токен]
POST /api/webcam   {userId,dataBase64}      [токен] — снимок в архив (120 дней)
POST /api/telegram {text}                   [токен] — отправка в канал
POST /api/backup                            [токен]
POST /api/files    {name,dataBase64} → URL  [токен]
GET  /files/<имя>
```

Пример датчика:

```bash
curl -X POST http://192.168.1.10:8080/api/sensors \
  -H "Content-Type: application/json" \
  -d '{"name":"temp_myasnoy","value":4.2,"unit":"°C"}'
```

## Локальный режим (без сервера)

Если сервер не запущен, приложение показывает жёлтый индикатор «Локальный режим» и продолжает
работать: данные в браузере устройства. Поднимите сервер — база синхронизируется автоматически.
Полная инструкция — в приложении: «Инструкции и API» → «Локальный режим и запуск».

## Веб-камера терминала

Включается в Настройках админки. При отметке терминал делает снимок → показывает 3 секунды →
снимок уходит в архив (раздел «Снимки камер»): управление сверяет, тот ли человек отметился,
может подтвердить/пометить, отправить на стену или в личку, скачать. Сжатие настраивается,
хранение 120 дней, файлы — на диске сервера.

## Структура

```
server/
  launcher.py        сервер + трей + API + автокопии + очистка снимков
  install.py/.bat    автоустановка и ярлык
  requirements.txt   зависимости Python
  data/
    smenalan.sqlite  база (бессрочно)
    db.json          зеркало базы
    files/           фото, вложения, снимки камер (120 дней)
    backups/         еженедельные копии
  server.log         журнал
```
