# СменаЛАН · локальный сервер (Python + трей)

Сервер раздаёт систему учёта смен всем устройствам в одной Wi-Fi сети и живёт в системном трее.

## Установка (один раз)

1. Установите **Python 3.8+** (python.org, при установке поставьте галочку *«Add Python to PATH»*).
2. Откройте папку `server/` в терминале и запустите:

   ```
   python setup.py
   ```

   Установщик сам:
   - проверит и докачает зависимости (`pystray`, `Pillow`, `qrcode`);
   - проверит Node.js и соберёт фронтенд в `dist/` (если сборки ещё нет);
   - создаст `server/config.json` и ярлык **«СменаЛАН Сервер»** на рабочем столе;
   - покажет IP и готовую ссылку для сотрудников.

3. При первом запуске Windows спросит про брандмауэр — **нажмите «Разрешить доступ»**,
   иначе телефоны не увидят сервер.

## Запуск

- Ярлык на рабочем столе **«СменаЛАН Сервер»** (или `python server/server.py`).
- Для отладки с консолью: `start_debug.bat`.

## Иконка в трее

- **Скопировать ссылку для сотрудников** — `http://<IP>:8080` в буфер обмена;
- **Скопировать IP-адрес**;
- **Открыть в браузере**;
- **QR-код для телефона** — картинка с QR сохраняется в `server/data/qr_connect.png` и открывается;
- **Настройки сервера…** — порт, автооткрытие браузера, автозапуск вместе с Windows;
- **Перезапустить сервер**, **Открыть папку с данными**, **Выход**.

## Пароли демо-доступов

| Логин   | Пароль | Роль       |
|---------|--------|------------|
| `root`  | `root` | Суперадмин (удалить нельзя) |
| `plan`  | `1234` | Админ      |
| `igor`  | `1234` | Сотрудник  |
| `marina`| —      | Сотрудник без пароля |

PIN киоск-терминала: `1234` (меняется в админке → Настройки).
Все пароли/логины сотрудников меняются в админке: *Сотрудники → изменить*.

## Как хранятся данные

- Общая база — `server/data/db.json` (копия предыдущей версии — `db.prev.json`).
- Фронтенд синхронизируется с сервером автоматически: при запуске загружает общую базу,
  каждое изменение отправляет на сервер. Индикатор «Сервер · синхронизация» в шапке
  показывает состояние. Если сервер недоступен, приложение работает в локальном режиме.
- Резервная копия и перенос на другой ПК — админка → *Данные / Excel → JSON*
  (или просто скопируйте `db.json`).

## Сеть

- Раздайте ПК **статический IP** в роутере (DHCP-резервирование), чтобы ссылка не менялась.
- Если порт 8080 занят, сервер сам возьмёт следующий свободный (видно в уведомлении трея),
  либо задайте свой порт в настройках трея.
- Проверка с телефона: откройте ссылку из трея в браузере телефона, подключённого к тому же Wi-Fi.
  В PWA-режиме приложение можно «Установить» на главный экран.
