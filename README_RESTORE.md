## 🔥 КРИТИЧНЫЕ ПРОБЛЕМЫ (11 штук)

### 1. Камера работает постоянно
**Симптом**: Камера включается при открытии настроек и не выключается  
**Причина**: Камера открывается глобально в Kiosk.tsx  
**Решение**: Камера должна открываться ТОЛЬКО в модальном окне FaceCheck

**Файл**: `src/components/Kiosk.tsx`  
**Исправление**: Убрать глобальное превью камеры, оставить только в FaceCheck

### 2. Игры с ИИ перезагружают страницу
**Симптом**: При нажатии "Играть с ИИ" сервер обновляется, страница перезагружается  
**Причина**: Создание игры вызывает синхронизацию с сервером  
**Решение**: Игры с ИИ должны быть локальными

**Файл**: `src/screens/ai-games.tsx`  
**Исправление**: Использовать локальное состояние вместо store

### 3. Версия сервера постоянно растёт
**Симптом**: Версия растёт с каждым изменением настроек (v155, v178)  
**Причина**: Каждое изменение настроек вызывает синхронизацию  
**Решение**: Debounce для сохранения настроек

**Файл**: `src/lib/store.tsx`  
**Исправление**: Добавить задержку 2 секунды перед сохранением

### 4. Чаты вылетают после сообщений
**Симптом**: После отправки сообщения происходит перезагрузка  
**Причина**: Синхронизация после каждого сообщения  
**Решение**: Оптимистичное обновление UI

**Файл**: `src/screens/misc.tsx`  
**Исправление**: Добавлять сообщение локально сразу, затем отправлять на сервер

### 5. Автозапуск не сохраняется
**Симптом**: Тумблер автозапуска не работает  
**Причина**: Нет API эндпоинта для автозапуска  
**Решение**: Добавить API эндпоинт

**Файл**: `server/launcher.py`  
**Исправление**: Добавить обработку `/api/autostart`

### 6. Загрузка файлов по одному
**Симптом**: Можно загрузить только по одному файлу вместо 10  
**Причина**: Неправильный обработчик файлов  
**Решение**: Исправить обработчик

**Файл**: `src/screens/misc.tsx` (FeedView)  
**Исправление**: Цикл по файлам с лимитом 10

### 7. Рисунки не отображаются на стене
**Симптом**: Нарисованные рисунки не сохраняются  
**Причина**: Canvas не конвертируется в dataURL  
**Решение**: Исправить конвертацию

**Файл**: `src/screens/misc.tsx` (FeedView)  
**Исправление**: `canvas.toDataURL('image/png')`

### 8. Стена постоянно обновляется
**Симптом**: Стена перезагружается каждые несколько секунд  
**Причина**: Синхронизация каждую секунду  
**Решение**: Увеличить интервал синхронизации

**Файл**: `src/lib/store.tsx`  
**Исправление**: `setInterval(sync, 5000)` вместо 1000

### 9. Онлайн игры не работают
**Симптом**: Баги в крестиках-ноликах  
**Причина**: Неправильная проверка ходов  
**Решение**: Исправить логику игры

**Файл**: `src/lib/games.ts`  
**Исправление**: Проверка цвета фигур в шахматах

### 10. Telegram бот 400 ошибка
**Симптом**: Ошибка 400 при отправке в Telegram  
**Причина**: Неправильный формат запроса  
**Решение**: Исправить отправку

**Файл**: `server/launcher.py`  
**Исправление**: Правильный JSON формат

### 11. Бот не понимает команды с маркерами
**Симптом**: Команды с "•" не распознаются  
**Причина**: Маркеры не удаляются перед парсингом  
**Решение**: Очистить текст от маркеров

**Файл**: `src/lib/store.tsx`  
**Исправление**: `text.replace(/^[\s•\-\*]+/, "").trim()`

## 🚀 ВОССТАНОВЛЕНИЕ ПРОЕКТА

### Шаг 1: Запустить скрипт восстановления

```bash
chmod +x restore.sh
./restore.sh
```

Этот скрипт:
- Создаст структуру директорий
- Восстановит package.json
- Установит зависимости
- Восстановит index.html, manifest, service worker

### Шаг 2: Восстановить файлы из документации

Все файлы описаны в документации:
- `src/lib/types.ts` — типы данных
- `src/lib/store.tsx` — хранилище состояния
- `src/lib/time.ts` — утилиты времени
- `src/lib/games.ts` — логика игр
- `src/lib/ai.ts` — ИИ функции

- `src/components/Kiosk.tsx` — киоск терминал
- `src/components/Login.tsx` — экран входа
- `src/screens/*.tsx` — все экраны
- `server/launcher.py` — сервер
